## Core results

ICLR 2024. Defines **intrinsic self-correction** (no oracle, no external feedback) and shows it
*reduces* reasoning accuracy across the board. GPT-3.5, GPT-4, GPT-4-Turbo, Llama-2-70b-chat on
GSM8K / CommonSenseQA / HotpotQA, up to two correction rounds:

- GPT-4 GSM8K 95.5% → 91.5 (round 1) → 89.0 (round 2); GPT-3.5 CommonSenseQA 75.8% → 38.1 → 41.8;
  Llama-2 GSM8K 62.0% → 43.5 → 36.5. Every model, every benchmark, every feedback-prompt variant
  tried: no intrinsic gain (Tables 2–5).
- Prior claimed gains (Reflexion, RCI) came from **oracle labels** deciding when to stop — with
  ground truth removed, the improvement vanishes (Table 1 vs 2). "Determining how to prevent
  [correct→incorrect] mischanges is, in fact, the key" (§3.3).
- Mechanism: models cannot judge the correctness of their own reasoning; **correct→incorrect
  flips outnumber incorrect→correct** (Fig. 1). GPT-4/Turbo mostly retain answers; weaker models
  flip more.
- **Multi-agent debate ≤ self-consistency at equal response count** (GSM8K: debate 83.2/83.0 at
  6/9 responses vs self-consistency 85.3/88.2) — "debate" is a costlier voting mechanism (§4).
- **Prompt-design confound (§5):** several published self-correction wins came from
  underspecified initial prompts; putting the full requirement in the initial instruction beat
  standard+self-correct (CommonGen-Hard: 81.8% initial vs 75.1% after correction).
- What *does* work (§6): external grounded feedback — code execution and unit tests as verifier
  ("the code executor serves as the perfect verifier"), tools, trained critics.

## Relevance to A/B/C

- **C — central.** Our review rounds are structurally self-correction with the same base model:
  absent new external evidence, additional critique rounds are expected to degrade, not improve —
  and the correct→incorrect asymmetry is exactly the "fair-looking finding that makes things
  worse" shape.
- **B — supporting.** Verdicts on claims the model cannot check (comment prose) are the purest
  intrinsic-judgment case, hence noise.
- **A — none.**

## Supported interventions

1. **Anchor every fix-triggering verdict in external evidence** — tests, execution, analyzers,
   spec text (catalogue C1/C2); the paper names test execution as the working verifier.
2. **Keep round caps tight** (C3): more intrinsic rounds monotonically hurt in their data.
3. **Don't add debate-style multi-reviewer discussion**; if redundancy is ever wanted, use
   independent samples + majority vote, which dominates debate at equal cost (D3).
4. **Fully-specified initial instructions over corrective feedback** (§5's confound inverted):
   requirements belong in the plan/AC up front, not discovered through review rounds — supports
   acceptance-criteria-first design.

## Applicability caveats

2023-era models on short QA/reasoning tasks; two rounds max; our reviewers *do* read real diffs
(more external signal than pure intrinsic critique), so the setting is adjacent rather than
identical. GPT-4's relative robustness suggests frontier models flip less — but the asymmetry's
direction was consistent across all four models tested.

## Briefing check

Confirmed as stated — this is the paper behind "review verdicts without external feedback are
unreliable and can degrade output." Two additions worth carrying: the multi-agent-debate result
(pre-empts a tempting "add a second discussing reviewer" fix), and the prompt-design confound
(apparent review value can be an artifact of underspecified upstream instructions — measure
against a fully-specified baseline before crediting review rounds).
