# Per-paper extraction reports

One extract per source in [../../../research.md](../../../research.md)'s reading list, same basename as the
mirror in [../articles/](../articles/), plus `effort-documentation.md` for S8. Produced
2026-08-14 during the session that wrote [../../../interventions.md](../../../interventions.md).

Each follows the same structure: **Core results** (with effect sizes and section/table citations),
**Relevance to A/B/C** (the briefing's three observed problems), **Supported interventions**,
**Applicability caveats**, and a **Briefing check** (whether the paper supports the one-line
relevance note research.md filed it under — several corrections surfaced this way; they are
consolidated in interventions.md §2).

Provenance is in each file's frontmatter: the six ★ papers and the effort docs were read in full
by the session lead; the twelve non-starred papers were extracted by structured-brief subagents
(Sonnet) reading the full article mirrors, reports preserved verbatim. Extracts compress; when a
claim is load-bearing, verify it against the article mirror.
