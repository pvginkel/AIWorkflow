# Per-source extraction reports — research run 2 (context economics)

One extract per source in [../research-2.md](../research-2.md)'s reading list, same basename as
the mirror in [../articles/](../articles/) (arXiv papers) or `web-<slug>.md` (the Chroma report,
vendor docs, practitioner posts). Produced 2026-08-22 during the session that wrote
[../interventions-2.md](../interventions-2.md). Run 1's extracts are frozen under
[../archive/run-1/extracts/](../archive/run-1/extracts/).

Each follows the structure in the extraction brief: **Core results** (effect sizes, models,
table/section citations), **Method and setting**, **Relevance to P1–P4** (the briefing's four
observed problems, with the transfer gap to our loop stated), **Interventions this paper
supports**, **Applicability caveats**, and a **Briefing check** (whether the paper supports the
one-line relevance note research-2.md filed it under — several corrections surfaced this way; they
are consolidated in interventions-2.md §2).

Provenance is in each file's front matter. Every source was extracted by an Opus agent reading the
full mirror (or the sections the briefing named — marked `read: partial`); the seven ★ sources were
additionally checked by the session lead against the article. Two practitioner sources gather
several pages into one extract (`web-claude-code-docs-harness.md` covers nine Claude Code docs
pages; `web-cognition-multi-agents.md` the 2025 post and the 2026 follow-up the briefing asked us
to locate). Extracts compress; when a claim is load-bearing, verify it against the mirror.

**Conversion caveat.** The LaTeX→Markdown path drops some tables silently (noted in the affected
extracts: 2505.06120, 2512.24601, 2601.16746, 2605.14563, 2606.29718); the agents recovered the
numbers from arXiv's HTML rendering where they were load-bearing. Two papers (2509.23586,
2510.00615) were converted from the HTML rendering outright (`arxiv_to_md.py`'s fallback).
